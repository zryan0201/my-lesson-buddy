# Character development fixtures

`demo_robot_drawing.png` is original project demonstration artwork.

`rough_robot_demo.png` applies deterministic coordinate wobble and coarse resampling to that artwork. It is a **simulated rough sketch**, not a real child's drawing. It is used to demonstrate and inspect the optional local cartoon-makeover pipeline. Demo results do not establish quality across children's drawings or learning outcomes.

Character packages in this folder are portable example assets for local import tests.

# Character Studio

A separate character-authoring module for My Lesson Buddy. Children can draw an original character or combine original hero-inspired parts. It runs without a vision model, an API key, or a paid service.

## Run in VS Code

From the project folder, activate the same environment used by the lesson app:

```sh
source .venv/bin/activate
python -m character_studio
```

Open **http://127.0.0.1:8601**. Keep this terminal open. Control+C stops the studio. `--port 8602` selects another port. For a fresh standalone installation, install `requirements-character.txt`; the full web environment already contains these dependencies.

## Create a character

**Draw it** works with a mouse, touch, or stylus. Use **Brush**, **Eraser**, **Line**, **Rectangle**, and **Circle** to make the character, then tap **Fill** inside a closed area to color it. **Mirror** draws both sides together. Choose colors and brush size, bring in a PNG/JPEG, and use **Undo** or **Redo** to try different ideas. Keyboard shortcuts also work while drawing: Command/Ctrl+Z to undo, and Command/Ctrl+Shift+Z or Ctrl+Y to redo.

**Preview polish** cleans up the drawing locally and removes near-white paper connected to the edge. It shows both versions and asks which to keep. This cleanup is not AI. The original remains downloadable, and applying a result is undoable. Drawings photographed on dark or textured paper may need cropping or background cleanup elsewhere.

**Build it** combines body, face, eyes, mask/helmet/ears/antenna, chest symbol, cape/wings, hands/gloves, boots, and four colors. Four starter designs provide a starting point. Every piece is original artwork generated by the local renderer; no character-image downloads are needed. Choosing a preset replaces the parts selection, while the separate drawing remains available.

Your drawing, parts selection, name, and mirror setting are saved automatically in this browser on this computer when browser storage is available. In-page confirmations help protect the draft before clearing, replacing a drawing, or opening a saved character for editing. Cancel keeps the current work; clearing or replacing a drawing can also be undone while the page remains open. Save an important parts draft before opening another design. Browser drafts and undo history are conveniences, not backups—large drawings may exceed browser storage, and clearing browser data removes drafts.

## Save, reopen, and share characters

Give the character a name and click **Save my character**. Each save makes a new entry in **Your character collection** and leaves earlier saved versions intact. Use **Find a buddy** to search by name, then click a character to open its preview.

- **Edit a copy** reopens the character's parts in Build mode or its picture on the drawing canvas. Make changes and save to create a new character; the saved original stays intact.
- **Make a twin** immediately saves an identical new character without replacing the current draft. Use **Edit a copy** on the twin to change its name or look.
- **Character package** downloads a `.character.zip` containing the transparent PNG, editable parts data when available, and a short README. Choose **Import a character** above the collection to restore a package under 8 MB as a new saved character. Importing leaves the current draft alone and preserves the package's exact artwork.
- **Download PNG** saves the picture for use elsewhere. A PNG contains the finished picture; use the character package to retain editable parts as well.

To try an animation, open a saved character, choose an action under **Try a move**, and click **See me move**. Wave, explaining, and celebration previews run locally; they do not generate a lesson or contact an AI service.

Drawing uploads accept PNG/JPEG under 8 MB and at most 12 million pixels. Saved artwork uses 600 × 800 RGBA PNGs. Packages are validated data files, never executable projects. Names support 1–32 letters/numbers, spaces, apostrophes, and hyphens, including non-English letters.

## Use it in a lesson video

Keep the studio running and open a second VS Code terminal:

```sh
source .venv/bin/activate
python -m lesson_video.web
```

After saving, click **Use in my lesson** in the studio. The link opens Lesson Buddy with that saved character already selected. The lesson app must be running at its usual address, **http://127.0.0.1:8501**. Selecting a character does not start a worksheet reading or generate a video.

You can also open Lesson Buddy directly, select **Studio library** in **Choose a friend**, and choose a saved character. Use **Refresh my character library** if you just saved it. If you run the lesson app on another port, open that address directly and select the character from the library. Add a worksheet, click **Read my picture**, and continue through the normal adult review and **Make my video** steps.

The lesson service copies the character PNG into the lesson job before reading. For compatible parts designs it also saves the exact editable design used for animation. The reviewed math, picture, character, design, and object artwork are protected by hashes. Rendering uses those saved snapshots, so later library changes cannot silently change a reviewed video.

Characters made from compatible studio parts now move their arms, wave, blink, open their mouths while explaining, and raise their arms to celebrate. These are simple animation loops matched to the lesson's actions, rather than sound-by-sound lip sync. Drawings and imported artwork whose pixels do not match the current parts renderer move intact with gentle tilting, bobbing, and celebration sparkles. This preserves the child's actual picture instead of guessing where its mouth or limbs belong. Older packages keep their saved appearance; editing and saving their parts creates a new version with the current renderer.

Default library: `.cache/character_studio/characters/`. Both apps must use the same project copy to see the same library. For a shared custom location, set `CHARACTER_STUDIO_STORAGE` to the same absolute path in both terminals. The studio also accepts `--storage-dir`; the lesson app still needs the matching environment variable.

## Gemini with a student subscription

A Gemini student-app subscription and the Gemini Developer API have separate access/billing arrangements. UChicago status alone does not establish API image-generation eligibility. As checked on October 26, 2026, Google's pricing lists image-generation API models without a free tier. Some text/image-understanding models have a limited free tier, subject to the API project's actual quota and billing status. Verify your own account before enabling requests.

With existing **Gemini app** access, expand **AI beautify with Gemini** in Draw mode:

1. Download the drawing PNG.
2. Open Gemini using your own account, attach the drawing, and use the provided makeover request.
3. Download a result you like and bring it back with **Bring a drawing**.
4. Save it to the character library and choose it in a lesson.

This manual workflow does not send anything automatically or use a developer API key. The original drawing remains available.

### Optional automatic API connector

The code includes Gemini image editing and Gemini worksheet reading, disabled by default. No live Gemini request was made during development because only a student subscription was available and no API key was configured. Provider integration is covered by mocked tests; live account/model access must still be verified.

An adult can create/check a separate key and its project limits in [Google AI Studio](https://aistudio.google.com/apikey). Keep the key out of chat, browser code, exported packages, and source control. To enter it into the current **zsh** terminal without displaying or saving it in a command:

```sh
read -s "GEMINI_API_KEY?Gemini API key (hidden): "
export GEMINI_API_KEY
export GEMINI_ENABLED=1
```

After checking the account's image-model access and charges, explicitly enable image requests and restart the studio from that terminal:

```sh
export GEMINI_IMAGE_ENABLED=1
python -m character_studio
```

The image feature requires both flags and the key. It shows an adult confirmation checkbox for each drawing sent to Google. A request produces a preview only; the child chooses whether to keep it. There are no automatic API retries, and rejected/failed generation leaves the original intact. The default image model is `gemini-nano-banana-2.1`; `GEMINI_IMAGE_MODEL` may select another compatible Interactions image model after its access and pricing are checked.

To use Gemini for worksheet reading, start the lesson app from a terminal with the key and `GEMINI_ENABLED=1`:

```sh
python -m lesson_video.web --reader gemini
```

Or inspect one picture from the command line:

```sh
python -m lesson_video --image "examples/worksheets/user_popsicle_addition.png" --reader gemini --inspect-only --out output/gemini_picture_check
```

Gemini describes the exercise; the existing Python validator computes and checks the math, and an adult still reviews it. `GEMINI_VISION_MODEL` defaults to `gemini-3.8-flash`. Normal launching without the reader switch continues to use the local Qwen model. Narration and video rendering remain local; this integration does not call a Google video-generation API.

Google requests use a fixed HTTPS endpoint, server-side credentials, bounded image/response sizes, metadata-free re-encoding, and `store:false` for Interactions conversation state. This setting does not override Google's account-level service/data terms. The studio is bound to localhost and has no production accounts or cloud hosting.

Official references: [student offers](https://support.google.com/googleone/answer/17422238), [API pricing](https://ai.google.dev/gemini-api/docs/pricing), [image editing](https://ai.google.dev/gemini-api/docs/image-generation), [image understanding](https://ai.google.dev/gemini-api/docs/image-understanding), [Interactions API](https://ai.google.dev/gemini-api/docs/interactions-overview).

## Files and extension points

- `parts.py`, `motion.py`: validated parts catalog, jointed artwork, and local animation previews.
- `images.py`: bounded drawing import and local paper/line cleanup.
- `assets.py`: immutable character library, editable projects, copies, snapshots, and ZIP import/export.
- `app.py`, `static/`: independent Flask API and browser canvas/editor.
- `gemini_makeover.py`: optional image-editing adapter.
- `lesson_video/gemini_client.py`, `gemini_vision.py`: shared optional provider transport and worksheet reader.
- `lesson_video/characters.py`, `web_pipeline.py`: video rendering and snapshot integration.

Run all offline checks with `python -m unittest discover -s tests -q`. Tests never call Google or download a model. Larger real-child drawing and worksheet evaluations, classroom usability testing, automatic drawing rigs, and sound-by-sound lip sync remain follow-up work. Gemini connectors stay off by default; drawing, building, importing, animation previews, and the normal local lesson workflow require no API credentials or paid requests.

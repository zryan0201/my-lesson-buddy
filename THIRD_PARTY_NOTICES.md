# Third-party material

This public capstone repository contains project code, authored demonstration assets and a separately identified academic worksheet evaluation corpus. Public repository visibility does not relicense third-party material.

- **Website libraries, models and narration:** see [the website notices](web_site/dist/THIRD_PARTY_NOTICES.txt). Model weights, downloaded runtimes, dependency folders and API credentials are not checked in. Build browser libraries using the pinned package lockfile.
- **Worksheet benchmark:** see [the corpus attribution](benchmarks/worksheet_v1/ATTRIBUTION.txt), [the per-case source manifest](benchmarks/worksheet_v1/manifest.json) and [the curated source registry](worksheet_benchmark/sources.json). STA materials retain their Open Government Licence v3.0 attribution. Illustrative Mathematics tasks and their adaptations retain CC BY-NC-SA 4.0 terms. The mixed corpus is supplied for noncommercial academic evaluation and is separate from the child-facing website.
- **Synthetic stress images:** transformations are explicitly recorded as synthetic, paired to their source questions and subject to the corresponding source-material terms. They are not real phone photographs or children's handwriting.
- **Examples and character packages:** included files are project demonstrations. Local user-created character libraries and generated lesson exports are excluded from version control.

No general-purpose open-source license is selected for the project's original code in this publication. Third-party licenses apply to their respective components and materials.

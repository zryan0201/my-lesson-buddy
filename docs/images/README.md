# Showcase media

[Visual tour](../SHOWCASE.md) · [Project overview](../../README.md)

This folder contains documentation media, separate from the application's runtime assets. It uses real product screens and recorded project output. No AI-generated UI mockups or private child submissions are included.

| Assets | Origin and scope |
| --- | --- |
| `studio-home.jpg`, `character-builder.jpg`, `character-drawing.jpg` | Fresh browser screenshots of the public studio, November 9, 2026. The drawing screen imports the repository's demo robot. |
| `worksheet-entry.jpg`, `worksheet-review.jpg`, `lesson-playback.jpg` | Fresh screenshots using the authored 5+2 popsicle example. They do not establish automatic-reader accuracy. |
| `popsicle-lesson.gif` | Silent 26–34 second excerpt from a previously recorded, narrated browser lesson, exported at 10 fps and 900-pixel width. |
| `four-worlds.jpg` | Reused project capture of the authored story-gallery examples. |
| `photo-preparation-ui.png`, `photo-before-after.png` | Reused preparation UI capture and actual processing outputs on explicitly synthetic photo fixtures. |
| `python-lesson-app.png`, `python-character-studio.png` | Reused development captures of the separate Python apps with demo content. |

The original capture dates of reused images are not asserted. They were selected for this documentation update on November 9, 2026. The individual sources, transformations, and hashes are recorded in [provenance.json](provenance.json). GIF transcoding changes only presentation format, scale, and frame rate; screenshots have not been repainted or given fabricated results.

The benchmark preview is linked directly from its original contact sheet rather than duplicated here. Its [attribution](../../benchmarks/worksheet_v1/ATTRIBUTION.txt) and source-specific terms remain applicable.

To update a screenshot, navigate the actual relevant screen, use project demonstration content, and preserve the surrounding context. Keep authored examples, simulations, measured results, and planned features clearly distinguished. Avoid model downloads or paid requests just to capture a documentation screen.
